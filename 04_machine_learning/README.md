# LearnPredict — Machine Learning

## Studi kasus
Demo klasifikasi risiko keterlambatan pengumpulan tugas menggunakan fitur jumlah tugas, waktu belajar, dan riwayat keterlambatan. Aturan skor dibuat transparan untuk edukasi, bukan model ML terlatih.

## Fitur
- Antarmuka responsif untuk desktop dan ponsel.
- Interaksi menggunakan JavaScript.
- Data contoh/simulasi untuk tujuan pembelajaran.
- HTML, CSS, dan JavaScript tanpa framework tambahan.

## Cara menjalankan
1. Buka folder `04_machine_learning`.
2. Klik dua kali `index.html`, atau buka file tersebut melalui browser.
3. Coba ubah input/filter yang tersedia untuk melihat perubahan hasil.

## Catatan
Website ini merupakan prototipe studi kasus akademik. Hasil simulasi tidak boleh dianggap sebagai data operasional atau keputusan profesional tanpa validasi.
